## ℹ️ About

Big Swords R x Cosmicore Add-On is a compatibility mod which adds the big swords, glaives, scythes using Cosmicore's materials.


## ✨ Features

### **This add-on adds:**
- ⚔️️ **2 New Big Swords**
- ⚔️️ **2 New Glaives**
- ⚔️️ **2 New Scythes**
- 🛡️ **4 New Shields with new Perks and Weaknesses**
